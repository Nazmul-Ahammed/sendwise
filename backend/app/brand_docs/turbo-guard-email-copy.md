# Turbo Guard Operational Product Knowledge

Version 1.0, prepared 11 October 2026, reference release 1.1.4.

This operational record is derived from the supplied `Turbo-Guard-Knowledge-Base(2).md`. It is the current campaign-generation source for Turbo Guard. The longer legacy master brand document remains available for historical brand strategy, but this newer release-specific evidence controls product claims.

## Product scope

Turbo Guard is a freemium security plugin for self-hosted WordPress. It helps users detect supported malware and SEO spam, review findings, take supported cleanup actions, and reduce exposure through firewall, login security, 2FA, file-integrity, vulnerability, and site-hardening controls.

Free provides scanning and essential protection. Published materials describe limited Free cleanup. Pro adds unlimited cleanup for supported detected items, Live Traffic Monitor, optional AI Security Advisor, Geo Fence, scheduled vulnerability checks, and expanded controls. The separate Pro package was documented but not runtime-tested in the supplied review.

Minimum requirements: WordPress 5.6 or later and PHP 7.4 or later.

Primary users: WordPress site owners, website teams, freelancers, and agencies.

## Important qualifications

- A clean scan does not prove that every possible compromise has been detected.
- Unlimited cleanup removes the paid-tier quantity limit for supported detected items. It does not guarantee detection, repair, or recovery from every compromise.
- Cleanup is based on reviewable delete or quarantine actions. Keep an independent site and database backup.
- Google Search Console support is a cleanup workflow. Do not promise automatic complete de-indexing, immediate ranking recovery, or Google Ads reinstatement.
- Core checksum differences and vulnerability notices require investigation. They do not independently prove exploitation or malicious intent.
- File monitoring is periodic and depends on WordPress cron. Do not describe it as continuous real-time surveillance.
- The WordPress-hook firewall covers supported request patterns. Do not describe it as an edge-network firewall or comprehensive DDoS service.
- Optional AI advice requires the user's OpenAI API key. The regular Free scanner uses signatures, patterns, checksums, and rules rather than AI for every scan.
- Optional integrations can send documented metadata to WordPress.org, WPScan, ipapi.co, OpenAI, and Google APIs. Do not claim that every feature is offline or that no data leaves the server.

## Current feature evidence

- Supported PHP, JavaScript, HTML, image or binary, and database inspection paths are documented or observed in the public Free package.
- Results can include path, threat name, and severity, with ignore or mark-safe workflows intended to reduce false positives.
- File cleanup supports delete and quarantine. The observed delete flow attempts to create a ZIP backup of selected files, not a full-site backup.
- Local SEO-spam checks cover supported posts, files, options, redirects, sitemap evidence, and multilingual spam indicators.
- WordPress core integrity uses official checksum information when fresh references are reachable.
- Vulnerability lookup uses WPScan when a valid key is configured, with a more limited WordPress.org status fallback when it is not.
- Firewall checks cover supported SQL injection, XSS, directory traversal, suspicious upload, IP blocking, rate-limit, and bot patterns.
- Login controls include failed-attempt tracking, lockout configuration, and TOTP 2FA with recovery codes.
- Hardening controls include security headers, WordPress version hiding, user-enumeration blocking, XML-RPC controls, REST restrictions, and file-editor controls.

## PHP web-shell campaign angle

A backdoor or web shell is a hidden mechanism an attacker can use to access or control a site. The supplied product evidence confirms supported detection patterns such as C99, R57, WSO, and suspicious command-execution constructs. It does not explicitly confirm a `PHP2Shell` signature by name.

Approved treatment: PHP2Shell may be discussed as an educational example of the broader PHP web-shell risk, but copy must not claim that Turbo Guard specifically detects, blocks, or removes PHP2Shell by name unless product engineering supplies dated evidence. Connect the risk to Turbo Guard's supported malware-pattern scanning, review, delete or quarantine workflow, and Pro monitoring controls.

## Claim restrictions

Never claim that Turbo Guard is the only WordPress security plugin, provides 100 percent security, detects every threat, creates zero risk, guarantees that nothing breaks, guarantees rankings, instantly removes every Google result, never slows a website, replaces a complete backup, or provides a guaranteed managed incident-response service.

Do not invent certifications, customer stories, testimonials, benchmarks, support SLAs, detection rates, recovery rates, revenue outcomes, or compatibility guarantees.

## Approved positioning

Turbo Guard helps WordPress site owners find supported malware and SEO spam, review and clean detected issues, and strengthen everyday protection with Free and Pro tools.

Useful message themes:

- Find supported threats and understand the next step.
- Investigate local infection and search-visibility problems as separate but connected activities.
- Add practical protection around a website that supports enquiries, sales, or customer trust.
